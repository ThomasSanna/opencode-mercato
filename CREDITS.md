# CREDITS

`opencode-mercato` is a **transparently aggregated** catalog — it never owns
the data it shows. Everything users discover through Mercato comes from the
community sources below, and they are credited here so their work is never
repackaged as ours.

## Data sources

| Source | URL | What we use |
|---|---|---|
| **opencode.cafe** | https://www.opencode.cafe | Approved-extension list, queried via its Convex API (`extensions:listAllApproved`). |
| **awesome-opencode** | https://github.com/awesome-opencode/awesome-opencode | `registry.json` of community extensions. |
| **OpenCode ecosystem docs** | https://opencode.ai/v2/docs/ecosystem | Ecosystem table of official extensions. |

## Rules

- Aggregated data is credited, licenses are respected, and no source content is
  repackaged as our own.
- Any future data source **must** be added to this file in the same commit that
  introduces it (see AGENTS.md — Transparency rule).
